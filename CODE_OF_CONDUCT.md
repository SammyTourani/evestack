# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1.

In short: be respectful, assume good faith, and keep disagreements about the work rather than
the person. Harassment, personal attacks, and trolling get you removed from the project's
spaces — issues, PRs, discussions — regardless of how technically correct the underlying point
was.

Report violations by opening a confidential [GitHub security advisory](../../security/advisories/new)
or contacting the maintainer directly. Reports are handled privately.
